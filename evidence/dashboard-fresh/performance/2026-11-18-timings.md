# Timings from the fresh browser session

These are single navigation and request durations from the Cursor browser. They are not a load test.

| Measurement | Value | Source |
| --- | --- | --- |
| First login document | 1,883 ms, HTTP 200, DOM content loaded 1,336 ms | `performance.getEntriesByType('navigation')` on the first `/login` load |
| Logged-out access check | 1,799 ms, HTTP 401 | `/auth/verify-access` |
| Invalid email login | 2,432 ms, HTTP 400 | `/auth/email-login` |
| Unauthenticated `/map` document | 3,361 ms, HTTP 200, then the login form | Navigation entry after opening `/map` |
| Direct `/` after the blank page | 641 ms, HTTP 200, then `/login` | Navigation entry. A separate `/auth/verify-access` on that load was 267 ms and HTTP 401 |

No map-render time was measured. The map was not opened.
